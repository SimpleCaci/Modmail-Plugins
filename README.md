# Modmail Plugins

A personal fork of [hyvnie/Modmail-Plugins](https://github.com/hyvnie/Modmail-Plugins), containing extensions for Discord Modmail bots.

This repository preserves upstream plugin work and its original commit history. It is not presented as an original SimpleCaci project.

## Tech stack

- Python
- Discord bot commands
- Modmail plugin conventions

## Included experiments

The folders cover commands and moderation utilities such as status changes, slow mode, temporary mute, verification, user lookup, and small response plugins. Individual folders may include their own notes or requirements.

## Status

Legacy educational project. These plugins target an older Modmail ecosystem and have not been verified against current Discord or Modmail releases. They are preserved for historical context rather than recommended for a live moderation server.

## If revisiting

- Choose a current Modmail version and document compatibility.
- Remove editor-specific `.idea/` files.
- Consolidate dependencies and add command-level tests.
- Review permission checks before deployment.
